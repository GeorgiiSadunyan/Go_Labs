# Документация: Тесты интерпретатора (core/interpreter_test.go)

Этот файл содержит **Unit-тесты** (модульные тесты) для основной логики приложения. Здесь проверяется работа калькулятора, эмуляция командной строки и системы безопасности, *без* запуска полного приложения.

## 1. TestCalculator
**Что тестирует:** Математический движок.
**Зачем:** Убедиться, что парсер правильно разбирает выражения и приоритет операций.

* **Как работает:** Мы подаем на вход строку (например, `"2 + 2"`) и сравниваем результат с ожидаемым числом (`4`).
* **Особенности:**
    * Проверяет базовую арифметику (`+`, `-`, `*`, `/`).
    * Проверяет приоритет операций (скобки).
    * Проверяет типизацию (результат всегда должен быть `float64`).

## 2. TestCurl (Эмуляция сети)
**Что тестирует:** Команду `curl` внутри интерпретатора.
**Зачем:** Проверить, что программа умеет "скачивать" сайты, но **без реального выхода в интернет**. Это делает тесты быстрыми и независимыми от Wi-Fi.

* **Как работает:**
    1.  Используется `httptest.NewServer`: Go поднимает маленький локальный веб-сервер прямо внутри теста.
    2.  Этот сервер всегда отвечает фразой `"Hello from Test"`.
    3.  Мы скармливаем интерпретатору команду `curl <АДРЕС_ТЕСТОВОГО_СЕРВЕРА>`.
    4.  Проверяем, что в ответе вернулось `"Hello from Test"`.

## 3. TestSafeDirCheck (Тест безопасности)
**Что тестирует:** Функцию `findFileInSafeDirs`.
**Зачем:** Критически важный тест. Он гарантирует, что пользователь (или AI) не сможет открыть системные файлы (например, пароли или файлы Windows/Linux) через команду открытия файлов.

* **Как работает:**
    * Мы просим функцию открыть "опасный" путь (например, `/etc/passwd` или `C:\Windows\...`).
    * Мы просим функцию открыть путь с выходом назад (`../secret.txt`).
    * **Успех теста:** Функция **должна вернуть ошибку**. Если ошибки нет — тест провален (значит, защита дырявая).

## 4. TestDeepSeekValidation
**Что тестирует:** Валидацию перед отправкой запроса к AI.
**Зачем:** Чтобы не тратить деньги и время на пустые запросы к API.

* **Как работает:** Посылаем пустую строку `""`. Тест должен убедиться, что программа выдала ошибку валидации мгновенно, не пытаясь подключиться к реальному серверу DeepSeek.
